# Política de segurança

Este repositório é uma referência educacional de Domain-Driven Design em Python. Não use o código
como está em produção sem revisão: segredos, autenticação e configuração de infraestrutura dos
exemplos são didáticos.

## Como reportar

Encontrou uma falha real (por exemplo, uma dependência vulnerável ou um problema no CI)? Reporte de
forma **privada** pelo
[GitHub Security Advisories](https://github.com/LoboProgrammingg/DDD-Structure/security/advisories/new).
Não abra issue pública.

Inclua: arquivo afetado, descrição do problema e, se possível, como reproduzir.

## Prazos

| Etapa | Prazo |
|---|---|
| Confirmação de recebimento | até 3 dias úteis |
| Avaliação inicial | até 10 dias úteis |
| Correção e divulgação coordenada | conforme a gravidade |

## Versões suportadas

Apenas a versão mais recente da branch `main`.
